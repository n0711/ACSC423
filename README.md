# ACSC423 - Frederick University

## Poolside AR assignment

The complete Android project is in **[PoolsideAR](PoolsideAR/README.md)**. Open that folder in Android Studio, or double-click **Open-Poolside-Android-Studio.bat** on Windows.

- [Implementation and architecture](PoolsideAR/docs/ARCHITECTURE.md)
- [Big-O analysis](PoolsideAR/docs/COMPLEXITY.md)
- [UI effectiveness](PoolsideAR/docs/UI_EFFECTIVENESS.md)
- [Tests and verification limits](PoolsideAR/docs/TESTING.md)
- [Recovery provenance and scope](PoolsideAR/docs/PROVENANCE.md)

The app offers camera-free replay, optional tabletop AR, playback controls, and a ball-memory challenge using synthetic data. Build the APK with the included Gradle wrapper. GitHub Actions also uploads APK and test-report artifacts after each successful run.
